# Resmigunler.com

Resmi tatil takvimi + izin planlama aracı. Tatilleri gör, tatil süresini uzatmak için izin kombinasyonlarını planla.

## Özellikler
- Resmi tatil listesi ve detay sayfaları
- İzin planlama önerileri
- Kalan gün sayacı ve tatil önerileri
- Görsel kartlar ve hızlı linkler

## Teknoloji
- React 19 + Vite 6
- TypeScript
- Tailwind CSS + Framer Motion
- React Router

## Kurulum
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Opsiyonel Ayar
`GEMINI_API_KEY` (varsa) `.env` dosyasına eklenir.
